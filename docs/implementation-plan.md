# Implementation plan — PaperY0/wavelets

Status: **v0.1.0 complete** (42/42 tests, 1771 golden differential cases).
This document records how the port was built and how to extend it.

## 1. Goal and ecosystem gap

Port [PyWavelets](https://github.com/PyWavelets/pywt) (the de-facto standard
wavelet library in Python) to MoonBit as a pure-computation module. A full scan
of the mooncakes registry (3983 modules, 3838 after excluding test/withdrawn)
found **zero** wavelet/DWT/CWT/PyWavelets/daubechies/morlet matches: existing DSP
modules only do FFT/FIR/IIR, and the one JPEG2000 decoder embeds an inverse
transform inside its codec rather than exposing a wavelet API. The niche is
empty, so the project follows the same pattern as the author's other ports
(`zxcvbn`, `crf`, `conllu`, `pronouncing`): mature-algorithm port + pure
computation + differential verification against the reference implementation.

## 2. Reference semantics (reverse-engineered, all verified)

The authoritative source is PyWavelets **1.8.0** installed locally under
`tools/ref/pylibs` (`pip --target`, never touching the global env). Semantics
were pinned by `tools/probe.py`, by reading the pure-Python modules
(`_dwt.py`, `_multilevel.py`, `_cwt.py`, `_functions.py`, `_thresholding.py`),
and by fetching `v1.8.0`'s `_pywt.pyx` from GitHub for `wavefun`.

Key rules (full detail in `docs/known-deviations.md`):

- **DWT output length**: non-periodization `(N+F-1)/2` (integer div);
  periodization `ceil(N/2)`. Convolution is reversed-filter + stride-2.
- **Periodization**: odd N is first even-extended by copying the last sample;
  the periodic extension pads `(F-2)/2` on each side (all discrete F are even).
  IDWT periodization uses window offset `(F-2)/2`, output length `2L`.
- **IDWT** requires equal-length cA/cD; `waverec` trims `cA == cD+1` per step and
  may return more samples than the input (upstream quirk, preserved).
- **upcoef**: detail branch uses `rec_hi` first then `rec_lo`; approximation uses
  `rec_lo` throughout. **downcoef**: keep approximation on intermediate levels,
  select `part` only at the last level.
- **wavefun**: orthogonal `n=(√2)^level`, `out_len=(F-1)·2^level+1`; biorthogonal
  `out_len=(F-1)·2^level` (no +1), decomposition side uses the inverse filter
  bank. Cascade via `upcoef`.
- **CWT (conv)**: integrate psi on a `2^precision` grid, build the reversed
  kernel at `count=ceil(scale·span+1)` samples, full convolution,
  `coef=-√scale·diff(conv)`, center-trim; `freqs=central_frequency/scale/dt`.
- **central_frequency**: `index = argmax(|fft(psi)[1:]|) + 2`, fold above Nyquist,
  `f=(index-1)/domain`.
- **threshold**: soft/garrote use `x·clip(1-t/|x|)` (NaN at `0/0`, signed zeros);
  greater/less compare the signed value.
- **dwt2**: rows then columns; `cA=LL, cH=LH, cV=HL, cD=HH`. **idwt2**: columns
  first, pairing `LL+LH → lo`, `HL+HH → hi`, then rows.

## 4. Verification strategy (three layers)

1. **Golden differential** (`golden_data_test.mbt`, generated by
   `tools/gen_golden.py`): 1771 cases across dwt/idwt/wavedec/updown/dwt2/
   wavedec2/cwt/wavefun/centrfrq/intwave/pad/threshold/maxlevel/coefflen/qmf/
   orthfilt, compared at `1e-9` (NaN encoded as JSON `null`).
2. **Property sweeps** (`property_test.mbt`): perfect reconstruction over 105
   wavelets × 9 modes × 9 lengths; multilevel & 2D roundtrips; filter-bank
   orthogonality; CWT linearity; branch additivity; dmey approximate bound.
3. **White-box** (`internal_wbtest.mbt`): upsample/conv/imod/extend_sample/FFT vs
   naive DFT/Hermite/linspace.

`tools/diff_test.py` additionally re-runs the **CLI** against a live PyWavelets
and rewrites `DIFF-REPORT.md`.

## 5. Reproduce

```bash
python -m pip install --target tools/ref/pylibs -r tools/ref/requirements.txt
python tools/gen_wavelets.py     # regenerate wavelet_data.mbt
python tools/gen_golden.py       # regenerate golden_data_test.mbt + tools/golden.json
moon info && moon fmt
moon test
python tools/diff_test.py        # CLI vs PyWavelets, writes DIFF-REPORT.md
```

## 6. Roadmap (post-0.1)

- Complex continuous wavelets (cgau/shan/fbsp/cmor) with a complex coefficient type.
- SWT (`swt`/`iswt`), wavelet packets, FFT-based CWT method.
- Custom filter banks (`Wavelet` from user-supplied filters).
- `central_frequency`/`integrate_wavelet` for discrete biorthogonal wavelets.
- Performance: precomputed extension tables, SIMD-friendly convolution.
