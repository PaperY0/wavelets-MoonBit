# wavelets 项目申报书

## 一、基本信息

- **项目名称**：wavelets（MoonBit 小波分析库）
- **参赛者**：PaperY0
- **GitHub 仓库**：https://github.com/PaperY0/wavelets-MoonBit
- **项目方向**：数据科学 / 数值计算 / 科学计算；音频 / 视频处理；压缩 / 编码工具
- **项目性质**：移植项目（参考 PyWavelets）

## 二、项目简介

wavelets 将 Python 事实标准小波库 PyWavelets 1.8.0 移植到 MoonBit，提供 1D/2D 离散小波变换、多层分解、连续小波变换、小波/尺度函数与阈值去噪，内置 106 个离散小波、10 个实值连续小波与 9 种信号延拓模式。纯计算、无 IO，支持 wasm / wasm-gc / js 三后端，滤波器系数与上游逐位一致。

## 三、项目方向与通用性

小波变换是时频分析、多分辨率分解、去噪与压缩的通用数学工具，不绑定具体业务。本库以纯函数 + 强类型枚举暴露能力，可被信号处理、图像压缩、特征工程、科学计算等上层库直接复用。对 mooncakes 全量 3983 个模块查重确认小波方向为零空白（现有 DSP 库仅做 FFT/FIR/IIR），本库填补该基础设施缺口。

## 四、预期使用场景

1. **信号去噪**：传感器/音频一维信号 → `wavedec` 多层分解 → `threshold` 软阈值细节系数 → `waverec` 重构输出干净信号；JSON CLI 便于嵌入数据管道。
2. **图像压缩与特征**：二维图像 `Matrix` → `dwt2`/`wavedec2` 得 LL/LH/HL/HH 子带 → 量化或丢弃高频子带 → `idwt2`/`waverec2` 重构，用于压缩或纹理特征提取。
3. **时频分析**：非平稳信号 → `cwt(mexh/morl, scales)` 得尺度–时间系数矩阵与对应频率 → 供可视化、故障诊断或生理信号分析下游消费。

## 五、拟实现核心功能

- 1D：`dwt`/`idwt`、`wavedec`/`waverec`、`upcoef`/`downcoef`、`dwt_max_level`/`dwt_coeff_len`；
- 2D：`dwt2`/`idwt2`/`wavedec2`/`waverec2`（行主序 `Matrix`）；
- 连续：`cwt`（卷积法）、`central_frequency`、`scale2frequency`/`frequency2scale`、`integrate_wavelet`、`wavefun`；
- 工具：`threshold`（soft/hard/greater/less/garrote）、`qmf`、`orthogonal_filter_bank`、`pad`（9 模式）；
- 106 离散 + 10 连续小波注册表与元数据查询；JSON CLI。

## 六、原创 / 移植说明

**移植项目**。参考项目：PyWavelets（pywt）；来源：https://github.com/PyWavelets/pywt ；许可证：**MIT**。本项目以 MIT 发布，LICENSE 保留上游版权。算法非原创，但 MoonBit 实现、强类型 API、数据生成器与差分验证体系为自行构建。
