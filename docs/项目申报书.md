# wavelets 项目申报书

## 1. 项目名称

wavelets（MoonBit 小波变换库）

## 2. 项目简介

PyWavelets 1.8.0 的 MoonBit 移植：106 个离散小波族 + 10 个实值连续小波，提供 1D/2D 离散小波变换与逆变换、多层分解、连续小波变换与阈值去噪。纯 MoonBit、零外部依赖，支持 wasm / wasm-gc / js 三后端。已发布 mooncakes：`PaperY0/wavelets@0.1.0`。

## 3. 项目方向与通用性说明

方向：数据科学 / 数值计算 / 科学计算；音频 / 视频处理；压缩 / 编码工具。小波变换是通用的时频分析基元，本库不绑定任何具体业务，任何 MoonBit 项目 `import` 即可调用；三后端覆盖浏览器、边缘与 Node 场景。已对 mooncakes.io 全量约 3983 个模块做关键词与人工复核，无同类小波 / DWT / CWT 库，零重合。

## 4. 预期使用场景（≥3）

1. **传感器 / 生理信号去噪**：`wavedec` → `threshold` → `waverec` 去除 ECG / 振动 / 音频噪声（见 examples/denoise）。
2. **图像多分辨率分解与压缩预处理**：`dwt2` / `idwt2` 做 LL/LH/HL/HH 子带分解（JPEG2000 类前置）。
3. **音频 / 振动时频分析**：`cwt` 生成尺度–时间系数图用于特征提取（见 examples/cwt_timefreq）。
4. **边缘 / 浏览器端信号处理**：wasm-gc / js 后端在端侧做去噪与特征提取，无需服务端。

## 5. 拟实现的核心功能

- 小波对象模型：106 离散族（haar / db / sym / coif / bior / rbio / dmey）+ 10 实值连续小波。
- 1D：`dwt` / `idwt` / `wavedec` / `waverec` / `upcoef` / `downcoef`，9 种延拓模式。
- 2D：`dwt2` / `idwt2` / `wavedec2` / `waverec2` / `dwt_max_level`。
- 连续小波：`cwt`（conv）、`wavefun`、`central_frequency`、`scale2frequency`。
- 去噪：`threshold`（soft / hard / greater / less / garrote）。
- 质量：43 个单元 / 黄金 / 性质测试（含 1771 条上游黄金差分），三后端全过；CI 覆盖 check/build/test 与上游差分。

## 6. 原创 / 移植 / 参考

**移植项目**（算法移植、实现代码原创）：将 PyWavelets 的算法与数值语义用 MoonBit 从零重写，非代码翻译。
