# wavelets 验收自查指南

对照赛事验收 9 条硬指标，逐条给出本仓库的落地证据与可复现命令。审核通过后无需再交表格，保持开发并推送 GitHub 即可；本指南供自查与评审复核。

环境前提：`moonc` ≥ 0.10.16（本仓库锁定 0.10.22，见 `.moonbit-version`）；`moon` 工具链；Python 3 + numpy/scipy 仅"上游差分/生成器"需要，库本体零依赖。

## 1. 以 MoonBit 为主要实现语言，moonc ≥ 0.10.16

- 证据：全部算法为 `.mbt`；`.moonbit-version` = `0.10.22+124d61d05`。
- 复现：`moonc -v`（应 ≥ 0.10.16）。

## 2. GitHub 仓库公开可访问，提交记录清晰

- 链接：<https://github.com/PaperY0/wavelets-MoonBit>（public）。
- 证据：commits 按功能层划分（小波模型 / 延拓 / DWT / 多层 / 2D / 连续小波 / 去噪 / 黄金测试 / CLI / 示例 / CI / 文档 / 发布），≥10 且无空提交。
- 复现：`git log --oneline`、`git rev-list --count HEAD`。

## 3. 源代码结构清晰，能完成声明的核心功能

- 证据：单包多文件按职责切分（`wavelet` / `wavelet_data` / `continuous` / `mode` / `dwt` / `multilevel` / `matrix` / `dwt2` / `wavefun` / `fft` / `cwt` / `threshold` / `errors`），`///|` 块风格，中文注释。
- 复现：`moon check`（0 error）；`moon ide outline wavelet.mbt` 等查看结构。

## 4. README 说明目标、安装、使用、示例，可复现

- 证据：`README.md` 含目标、安装（mooncakes / 源码）、API 用法、可运行示例、测试与发布说明。
- 复现：`moon add PaperY0/wavelets` 后按 README 调用；或克隆后 `moon run examples/denoise`。

## 5. 使用持续集成，覆盖检查、构建、测试

- 证据：`.github/workflows/ci.yml`：build 矩阵（wasm/wasm-gc/js）跑 `fmt --check`/`check`/`build`/`test`/CLI 与示例 smoke；interface job 跑 `moon info`；integration job 跑上游差分。GitHub Actions 全绿。
- 复现：本地 `moon check && moon build && moon test`；云端见仓库 Actions 页。

## 6. 至少一个可运行示例 / 最小使用样例

- 证据：`examples/denoise`（去噪 MSE 0.0309→0.0056）、`examples/cwt_timefreq`（chirp 时频脊线）。
- 复现：`moon run examples/denoise`、`moon run examples/cwt_timefreq`（输出见 examples/README.md）。

## 7. 完整测试，覆盖核心功能路径

- 证据：43 个测试 = 单元 + 1771 条上游黄金差分（`golden_data_test.mbt`）+ 完美重构/线性/Parseval 性质测试；三后端各 43/43。
- 复现：`moon test`；`moon test --target wasm-gc`；`moon test --target js`。

## 8. 发布到 mooncakes.io

- 证据：`PaperY0/wavelets@0.1.0` 已发布（`moon publish` 返回 200）。
- 复现：`moon search wavelets`；`moon add PaperY0/wavelets`；页面 <https://mooncakes.io/docs/#/PaperY0/wavelets/>。
- 注意：`moon publish` 会打包工作目录，发布前需临时移走 gitignore 的 `tools/ref/pylibs`（见 README/AGENTS）。

## 9. OSI 认可开源许可证；参考/移植符合原许可证

- 证据：`LICENSE` = MIT（OSI 认可）+ 上游 PyWavelets BSD-3-Clause 署名段落，满足 BSD  redistributions 保留版权与许可声明的要求。
- 复现：查看 `LICENSE`。
