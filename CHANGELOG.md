## [0.1.0] — 2026-11-26

First public release.

### Core
- MoonBit port of [PyWavelets](https://github.com/PyWavelets/pywt) 1.8.0, pure
  computation, no IO; `wasm` / `wasm-gc` / `js` targets.
- **106 discrete wavelets** (haar, db1–db38, sym2–sym20, coif1–coif17,
  bior/rbio families, dmey) + **10 real continuous wavelets** (mexh, morl,
  gaus1–gaus8), filter coefficients bit-identical to upstream (17 significant
  digits, generated by `tools/gen_wavelets.py`).
- **1D DWT/IDWT** with all **9 signal extension modes** (zero, constant,
  symmetric, periodic, smooth, periodization, reflect, antisymmetric,
  antireflect), including upstream's odd-length periodization and the
  "waverec may return more samples than the input" quirk.
- **Multilevel** `wavedec`/`waverec`, `dwt_max_level`/`wmaxlev`, `dwt_coeff_len`.
- **Partial transforms** `upcoef`/`downcoef` (multilevel branch semantics matched
  to upstream), `qmf`, `orthogonal_filter_bank`.
- **2D** `dwt2`/`idwt2`/`wavedec2`/`waverec2` on a lightweight `Matrix` type.
- **CWT** (convolution method) `cwt`, `central_frequency`, `scale2frequency`,
  `frequency2scale`, `integrate_wavelet`, and `wavefun` scaling/wavelet functions
  (orthogonal + biorthogonal sides).
- **Thresholding** `threshold` (soft/hard/greater/less/garrote) with upstream's
  exact boundary semantics (including the `0/0 → NaN` soft/garrote case and
  signed-zero preservation).

### API
- Strongly-typed `Wavelet`, `Mode`, `WaveletKind`, `Symmetry`, `CoeffPart`,
  `ThresholdMode`, `Matrix`, `Coeffs2`, `Decomposition2`, `Wavefun`; a single
  `WaveletError` suberror taxonomy.
- CLI: `moon run cmd/main -- <list|info|dwt|wavedec|cwt|wavefun|threshold|pad>`,
  JSON output for differential testing.

### Quality
- **42 MoonBit tests, all passing**, including **1771 golden differential cases**
  baked from PyWavelets 1.8.0 (`tools/gen_golden.py`) and property sweeps
  (perfect reconstruction across 105 orthogonal/biorthogonal wavelets × 9 modes
  × 9 lengths; 2D roundtrips; filter-bank orthogonality; CWT linearity).
- `tools/diff_test.py` re-runs the CLI against a live PyWavelets for end-to-end
  differential verification.

### Deliberate deviations from upstream (see docs/known-deviations.md)
- Complex continuous wavelet families (cgau/shan/fbsp/cmor) are out of scope for
  v0.1; only real-valued continuous wavelets are ported.
- `wavedec`/`wavedec2` raise `InvalidLevel` when the requested level exceeds the
  maximum useful level, instead of upstream's warning-and-proceed.
- `central_frequency` / `integrate_wavelet` are defined for continuous wavelets;
  the discrete biorthogonal `integrate_wavelet` path raises `NotSupported`.
- `wavefun` level is capped at 20.
- SWT (stationary WT), wavelet packets, the FFT-based CWT method, and custom
  filter banks are roadmap items, not in v0.1.
